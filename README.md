# TITeee

I build **[heretix](https://titeee.github.io/heretix-web/)**, a self-hosted, open-source (Apache-2.0) suite that tracks CVEs across servers, containers and network appliances in one inventory.

| Repository | What it does |
|---|---|
| [heretix-cli](https://github.com/TITeee/heretix-cli) | Scanner: package inventory of hosts and container images as CycloneDX SBOMs |
| [heretix-api](https://github.com/TITeee/heretix-api) | Vulnerability database API: NVD, OSV, CISA KEV, EPSS, distro errata and vendor PSIRTs |
| [heretix-management](https://github.com/TITeee/heretix-management) | Console: asset inventory, alert triage, SLA, VEX, Slack |
